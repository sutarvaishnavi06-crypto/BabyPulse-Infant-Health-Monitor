# 🌈 BabyPulse — Infant Health Pattern Monitor

### An Interactive Anomaly Detection System Using Isolation Forest

BabyPulse is a Flask-based web application designed to record everyday infant health observations, maintain health history, and identify unusual numerical patterns using the Isolation Forest machine learning algorithm.

The application combines interactive data visualisation, configurable anomaly detection, CSV dataset uploads, SQLite record management, and PDF report generation.

### Key Highlights
- Daily infant health record management
- Machine Learning-based anomaly detection
- Interactive Plotly.js visualisation
- Configurable Isolation Forest parameters
- CSV upload and sample datasets
- PDF health record reports

**Technology Stack:** Python | Flask | Scikit-learn | Isolation Forest | Pandas | NumPy | SQLite | HTML5 | CSS3 | JavaScript | Plotly.js
